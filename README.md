🚌 Bus Ticket Booking System

A Python-based Bus Ticket Booking System that allows users to search for buses, book seats, cancel tickets, and check seat availability. The application uses JSON files for storing and managing booking information.

📌 Project Overview

The Bus Ticket Booking System is a console-based application developed using Python. It simplifies the bus reservation process by providing essential booking operations, including bus searching, seat reservation, ticket cancellation, and booking history management.

The project uses JSON for data storage, making it easy to manage passenger and booking information.

✨ Features

- Bus Search: Search for available buses based on source, destination, and travel date.
- Seat Booking: Book available seats for selected buses.
- Ticket Cancellation: Cancel previously booked tickets.
- Seat Availability: Check real-time seat availability before booking.
- Input Validation: Validate user inputs to prevent invalid booking details.
- Booking History: View previously completed bookings.
- JSON Data Storage: Store and retrieve booking information using JSON files.

⚙️ Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/chanduvardhan22/bus-ticket-booking-system.git

2. Navigate to the project directory

cd bus-ticket-booking-system

3. Run the application

python app.py

Make sure Python is installed on your system before running the application.

💡 How It Works

1. Start the application.
2. Search for buses using source, destination, and travel date.
3. View available buses and seats.
4. Select a bus and book an available seat.
5. Cancel a booking when required.
6. View booking history and updated seat availability.
